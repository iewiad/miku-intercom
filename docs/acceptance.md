## S2 浏览器数字媒体验证

S2 实现 [PR #6](https://github.com/iewiad/miku-intercom/pull/6) 已合并至 main（`725fa81`），代码与数字验证提交 `f05e6ee`。本切片在 S1 控制面上增加浏览器麦克风采集、Pion WebRTC Opus 转发与媒体门控。普通页面只在显式启用后申请麦克风；开发诊断默认关闭，通过 `-media-diagnostics` 开启。诊断使用合成 440 / 997 / 1777 Hz 音源，测量来自远端 `ontrack` 的真实解码 PCM，没有读取 RTA 凭据、调用原网关或连接板子。

Go 1.27.1 下 47 个顶层测试、`go test -race ./...` 与 `go vet ./...` 通过。测试包括真实 Pion 传输、未获权/无 Peer 零转发、自然租约到期、独立群隔离、旧队列/回调、容量限制及十次连接清理；Node.js 26.3.1 下 46 条 JS 状态与诊断算法测试通过，包含音频失败后的显式重试恢复与多触点 PTT 回归。

三终端同页最终矩阵 10 项全部通过，原始机器报告见 [browser-matrix.json](evidence/2026-10-24-browser-matrix.json)。覆盖 A→B/C、B→A/C、C 切群后的双向隔离、松手排空后连续两秒静音、同时抢麦、故意停止续租且继续发包后的到期静音，以及十次切群/Peer 重建。A→B/C 的实际远端主频约 439 Hz，RMS 约 0.0707，codec 为 Opus/48000；到期测试接收端为静音，源 track 仍启用且上行继续增长。额外把获权者静音、败方保持上行，败方继续发送 110 包时 C 的 22 个有效远端 PCM 窗口 RMS 均为 0；自然到期后源继续发送 246 包，B/C 各 22 个窗口 RMS 均为 0。十次切群后每端仅一个有效 Peer，停止后 A/B/C 的开放 Peer 均为 0。包计数本身不作为有声证据，服务端空闲 Opus 静音用于维持下行播放。

两个独立 Chrome 页面使用不同测试身份同群互通，精简证据见 [browser-tabs.json](evidence/2026-10-24-browser-tabs.json)。B 收到 A 的 440 Hz（实测约 439.45 Hz），A 收到 B 的 997 Hz（约 996.09 Hz），两方向各 31 个有效有声样本，最大 RMS 分别为 0.07099 / 0.07094；两端均确认 Opus/48000 与有效解码时长，关闭后各自开放 Peer 为 0。完整原始 observations-only 导出保存在任务输出，仓库摘要记录其 SHA-256；通过结论来自预期频率与远端 RMS 的核对。

此前普通首页仅验到权限请求。本轮按用户要求，两个可见 Chrome 窗口均选择“仅此一次”允许内建麦克风，普通页面均进入可收听状态、PTT 可用；收听随后静音，关闭音频回到未启用。实际采集与传输见下一节。

数字诊断不代表系统麦克风、扬声器/耳机的人工听测，也不外推为局域网、公网或板端可用。普通页面隐藏时会关闭媒体；同机真实听测需两个保持可见的窗口和耳机。

## 真实系统麦克风采集与传输

2026-10-24 01:19–01:21（Asia/Shanghai），同机两个可见 Chrome 窗口、独立测试身份使用真实内建麦克风，沿用普通 AudioClient 默认 getUserMedia、正常麦权与 PTT。没有使用合成源或录音，接收播放保持静音。机器证据见 [system-microphone.json](evidence/2026-10-24-system-microphone.json)，包含原始任务输出 SHA-256、按次窗口、采集设置与远端统计。

两端均为 live、48000 Hz、单声道，启用 AEC / 降噪 / 自动增益。B→A 获权约 3009ms，30 个启用采集样本，源峰值 RMS 0.01612，A 远端峰值 0.01400；A→B 约 3010ms，30 个启用采集样本，源峰值 0.04286，B 远端峰值 0.04666。两方向接收 codec 均为 Opus/48000，解码时长增长；停止后的远端最新 RMS 为 0。立即取消的 283ms 窗口也观察到源 track 从 enabled=true 同步变成 false。全部测试 Peer 已关闭。

这次通过的是实际系统麦克风采集与群媒体传输。用户选择“先验证采集和传输，稍后听测”，因此真人语音清晰度、耳机/扬声器听感均保持待验；本轮未确认原生切标签是否触发隐藏事件，不将其计入真实闭麦验收。诊断数据只用于数值观察，不把包数或固定频率当作真实麦克风有声结论。

诊断页新增显式真实音源、正常 PTT、可取消的 3 秒驱动、收听重试、采集设置白名单与聚合报告；默认仍为合成矩阵，真实模式不创建 oscillator。55 条 Node 测试通过；Go 构建通过，合成三端矩阵在本修订上再次 10/10 通过；后端控制/媒体代码与 PR #6 保持一致。
