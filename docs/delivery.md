## 当前验收与边界

本轮完整标准离线检查在 `b15106e` 起止一致：25/25 项通过，含 149/149 Node 测试、34 个 Python 工具测试及 Go race/vet/build、板端 host/LVGL 回归，耗时 20.246 秒。服务和应用复用已验构建；软件检查与真人听感分别记录。

当前 v108 已补板↔A、板↔B四方向完整句、松手与滑出停发、滑回不续发、停止/重连；目标语音经原文核对、选卡不执行与明确确认，板端版本 34→35 后目标媒体就绪。独立 S5 已补板端准备返回、采集中取消、查看取消、自然到期与确认，以及浏览器文字建议/到期、待请求隐藏返回、语音物资卡核对与确认；板端 35→36、浏览器 9→10，确认后双向完整句与松手停发；后续板端真正查看取消与自然到期均维持版本 36、操作数 35。Issue #20 的板端与浏览器人工卡片核对均已通过。

这些结果保留以下限制，不写为零失败或 100% 准确率：

- 目标语音首次模型返回 0 候选，不计正向通过；第二次返回 1 候选后才由人核对、选择并明确确认。
- S5 首次未成功，实际转写未保留，不能将原因归给 ASR 或模型。一次最初被报告为取消的操作，后来由用户确认实际按了“确认进入”，仅计正向确认；后续真正取消与过期另有独立证据。
- 观察到 2 次控制 HTTP 失败，状态码与路径未直接定位。新操作查询 GET 404 是可能解释，尚未证明，不能称为已证实的丢响应重试或 TLS 故障。
- 模型候选与真人听测仅对这些用例、版本和观察窗口有效，不代表总体准确率或长期可靠性。

拍摄前验收最后已完成该轮三端关闭：板端 STOP/stop_complete、observer 退出且串口释放，A/B 音频关闭、PTT 不可用且未按麦，40/40 个已知语音会话为 stopped。用户确认“麦克风提示已消失，耳机和板子无回传”。不据此推断未知会话或未直接观察的原产品页 Peer 精确计数。
