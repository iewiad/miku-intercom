# S3 板端与局域网接入增量

状态：首切片实现及一板一浏览器数值验证通过，2026-10-24；以 002/003 为权威群控制和媒体协议。本切片先实现一板与浏览器的群连接/PTT/双向数值传输；人工听测、板端多群切换与 RTA 指令分别验收。

## 显式局域网入口

默认 localhost HTTP/Host/Origin/ICE 行为保留。仅配置完整的设备入口参数时，额外监听一个本机 RFC1918 IPv4 的 HTTPS 端口，复用同一控制服务和媒体 Hub。入口必须校验 TLS、精确 Host（含端口）；拒绝 Origin 和跨站 Sec-Fetch-Site，不信任转发头，不开通配 CORS。只开放鉴权 API，不提供静态页面、诊断或匿名 POST /devices；终端身份在本机入口预配。

媒体额外允许该指定 LAN IP，仍允许 loopback 供同机浏览器使用；配置限定的 UDP 端口范围，不使用任意地址候选、公共 STUN/TURN 或明文 LAN 控制。证书私钥留在本机忽略目录；浏览器继续用 localhost，不安装系统根证书。

## 板端配置与信任

配置单独存 NVS intercom namespace：服务 URL、CA PEM、独立 device_id/Token、首次入群口令。USB 工具从私有文件读取凭据，经原串口传递有界配置，不在命令行/日志回显；保留原 Wi-Fi、rti_auth 和音量设置，不擦整片 Flash/NVS。群固件未配置时显示配置入口，不自动创建 RTA Session。

板端验证 CA 链、IP/主机名及有效期，禁止跳过校验。本切片通过 USB 提供当前 UTC 时间，每次重启后重新同步，尚未接入自动 SNTP；无可信当前时间时连接失败并等待校时，不能绕过证书有效期。证书轮换通过显式重新配置。

## 单 Peer 与 PTT

复用硬件、Opus/AEC 与单 Peer 管线，群模式不用 oai-events、欢迎语或模型请求。完整 ICE offer/answer 使用 003 的 /media API；连接就绪前 PTT 禁用。群 Peer 与 RTA 不并存。控制 worker 在同一配置周期复用验证后的 HTTPS 连接，避免音频运行期间重复 TLS 握手挤占内部内存；响应不完整、解析失败或连接异常时销毁句柄，配置变化前先释放旧连接。

UI 的 pressed/released/press-lost 独立处理。按下申请匹配 peer_id、群版本、启动代次的麦权；只有 ACK 匹配且仍按住才发送。松手/取消先同步关闭源发送门，再异步 release；迟到授权补偿释放，绝不恢复按下。在 esp_peer_send_audio 前再次检查门与本地租约截止时间，续租失败/到期停发。断网、身份/群/启动代次变化关闭旧 Peer，恢复未按麦。服务端继续逐包授权。

群播放采用有界低延迟缓冲，不依赖 AI speaking 事件或无限等待长回复；允许浏览器合法 Opus 帧时长，维持 48k RTP 时钟与板端 16k I2S。群模式较大的非 DMA 音频工作区显式分配至 PSRAM，分配失败不回退占用内部内存；I2S 驱动的 DMA 缓冲、AEC DMA 数组及原 RTA 分配路径不变。只记录聚合发送/解码计数和 PCM 数值，不保存声音、设备硬件标识、Token 或 SDP。

## 验收

先做 TLS/Host/Origin/匿名注册边界与默认 localhost 回归；板端配置/校时/控制状态；一板一浏览器双向 Opus/非零 PCM，PTT获权/松手/续租/断网；随后多浏览器一对多、隔离与板端切群。构建、烧录、实际传输和人工听测分别记录。原 RTA 已通过不等于群接入通过。仅更新应用区，独立校验镜像并保留可恢复基线。
