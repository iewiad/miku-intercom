# 群职责与列表筛选：S5 基础切片

2026-10-25。PR #12 已合并，基础群对讲与明确群名语音切换继续按 [002](002-control-api.md) / [006](006-first-version.md) 工作。本切片为[产品规划](../product.md#按需求找到对应小组增强规划)中的需求推荐准备可用的群职责数据和浏览器查找入口，使用独立 PR 交付。

## 本切片行为

- 浏览器建群时可填写职责简介，例如“设备故障排查、音响和照明维修”；省略时与原建群行为相同。
- 已加入群卡片显示非空简介。成员可按群名或职责进行大小写不敏感的本地子串筛选，再主动点击原“进入”按钮。
- 筛选只改变列表显示，当前群卡片保持独立；不发起切群、变更成员资格、申请麦权或启用音频。它不是语义推荐，不宣称找到某个在线成员。
- 普通群对讲、按群名语音切换与所有恢复规则不变。职责不进入当前 RTA 指令提示、普通群音频或日志。

## 字段与权限

`POST /api/v1/groups` 接受 `{name,purpose?}`。`purpose` 省略或为 null 时为空；字符串按 Go `strings.TrimSpace` 使用的 Unicode White_Space 集合去除两端空白，之后允许 0–256 个 Unicode 码点，拒绝内部 Unicode Cc 控制字符及无效 UTF-8 字节。合法简介只作为纯文本数据，不解释 HTML、URL、脚本或指令。

浏览器入口的 `group` 和 `state.groups[]` 增加可选 `purpose`，非空时返回，空时省略。成员只取得自己已加入群的目录；不能通过职责绕过口令或列出未授权群。职责只在建群时填写，本片不提供编辑、owner 推断或撤权管理接口。

创建仍在原控制锁与持久事务内完成。简介不作为唯一群名、鉴权或切换标识；第二次建群/入群仍保留原当前群。保存失败时不发布新群、简介或成员资格，原当前群、版本和发言权保持原语义。

## 存储与旧客户端

- 快照仍为版本 1，群记录增加可选 `purpose`。新版本读取缺字段的旧快照时视为空；非法职责或非法 UTF-8 的快照拒绝加载，不静默修正原文件。
- **旧服务二进制会拒绝包含新字段的快照。** 升级已有环境前应保留停服后的一致快照副本；需要回滚时同时恢复对应旧快照。此操作不自动执行，也不删除旧数据或降低快照校验。新建空简介群仍使用原字段集合。
- 原 ESP32 设备 HTTPS 入口在所有 `group/state` 回包中省略 `purpose`，保持原群目录的字节规模，避免 128 个长职责突破固件约 48 KiB 的响应上限。控制面仍保存简介，本机浏览器入口仍可读取；未来板端展示职责需单独定义有界协议。
- 原浏览器、USB 配置工具、明确群名解析和切群载荷均可继续使用旧字段；不要求重刷板子、重建身份或迁移当前群。

## 验证

自动验证包含：

1. 省略/null/空白简介兼容，256/257 码点、多字节、控制字符和无效 UTF-8 边界。
2. 新旧快照读取、非法快照拒绝、保存失败回滚与未加入身份不可见。
3. 本机浏览器可见职责，设备入口所有群/状态回包省略职责且目录不因职责膨胀。
4. 建群请求和成功/失败表单处理；旧群缺字段显示；名称/职责筛选、无匹配反馈及恶意 HTML 纯文本展示。
5. 筛选不切群、不请求音频；原 PTT、语音指令、状态恢复及固件主机回归继续通过。

真实浏览器交互与模型推荐分别验收。本轮不开麦、不播放测试音、不访问原被阻止的浏览器页面、不调用 RTA，也不改动板端。

## 后续需求推荐的门槛

后续切片现由 [009 模型推荐契约](009-model-recommendation.md)落实；以下为当时冻结的门槛，007 本身仍只验收职责与本地筛选。新的真实模型与离线协议证据在 [acceptance.md](../acceptance.md) 单独列出，不追写成本切片的通过范围。

生产 RTA 代理目前只有会话、SDP 和停止管理；群名解析仅处理明确命令。参考工程中的 RTC 文本输入示例不证明当前 Profile 能稳定返回推荐。下一切片先验证原 RTA 的有界文本终态与禁播放能力，再接入生产推荐器；不预设 tools、结构化输出或可信置信度，也不新增未经验证的 Provider。

推荐必须在后台从已授权群生成候选，并绑定身份、当前群版本、服务启动代次、候选内容摘要与固定有效期。成员追加不会改变当前群版本，候选变化因此需要独立校验。模型输出、职责与需求只作不可信数据；目标必须能精确映射到本次候选，推荐阶段不执行切群。

用户明确确认后，后台须在同一控制锁与持久事务中重验权限、候选、有效期和版本，同时消费推荐、执行原切群并记录操作终态。相同确认重放应先返回已保存终态，再判断过期；丢响应、重启或候选变化不得造成重复切群。客户端继续确认原操作，目标权威状态与媒体恢复后才显示可对讲。具体端点、容量与时限留待真实模型能力验证后的独立契约冻结，本片不提供占位推荐结果或不可用按钮。
