# 语音目标理解与确认

2026-10-25。针对板端口述目标群未能精确命中的验收问题，用户授权引入模型辅助理解。本规格接替 [006](006-first-version.md) 中客户端直接解析后执行的路径；[009](009-model-recommendation.md) 的职责推荐仍为独立意图。

## 行为

用户主动开始一次语音指令；只接收本代次首个最终转写。关闭麦克风、本地命令 Peer，并确认已知 RTA 会话结束后，再请求语音目标核对。RTA 的转写配置不增加未经证实的热词、tool calling 或结构化输出字段。普通群对讲不会进入模型。

服务端先在本设备授权目录中执行原有完整群名精确匹配。唯一命中直接生成待确认结果，不调用模型；未唯一命中才使用原已验证 RTA 文本适配器和独立的 `voice-target` 提示。模型只见转写及本次授权候选的临时标识、群名和可选职责，不见真实群 ID、身份、成员或凭据。职责不能代替目标群名，用职责求助继续使用“需求找组”。

模型可理解自然表达、轻微同音或错字；否定、取消和没有切群意图时不给建议。明确改口只考虑最后仍有效的目标；多个合理目标最多展示三个，信息不足时返回空建议。群名、职责、转写和模型输出都是不可信数据。模型是否正确理解仍需实际评估；提示词不构成准确率保证，也不修复 ASR 本身。

**所有结果，包括精确命中，都必须展示群名，由用户点击“确认进入”后才提交切群。** 选择卡片、结果到达、超时、取消、返回、重新连接不能执行。固定说明为“请核对识别出的目标群，确认后才会切换。”，不显示模型自由理由，不声称已经进入或有人在线。

## API 与事务

新增 `POST /api/v1/voice/proposals`，请求 `{request_id,transcript,expected_version,server_epoch}`，响应 `{recommendation}`。认证、同源/原生 TLS 门禁、请求体、未知字段和无缓存规则沿用现有 API。转写去除首尾空白后为 1–256 个 Unicode 码点、最多 1024 UTF-8 字节，合法 UTF-8 且不含 Cc；板端继续使用原 512 字节上限。非法输入不进入模型。

`recommendation` 复用 009 的完整结构，并在该入口必含 `source=exact|model`。旧职责推荐可省略 source。客户端验证 source、请求 ID、epoch、版本、期限和授权目录中的完整候选信息；模型不能通过自报群名改变映射。旧 `/voice/resolve` 保留只读兼容，当前客户端不再用它直接执行。

复用 009 的单快照候选、候选摘要、20 秒模型期限、从快照起 60 秒有效期、每身份 1 个进行中/8 条记录、5 秒间隔与全局 256 条容量。请求摘要包含意图，避免与职责推荐的同一个 request_id 混用。唯一精确命中不依赖模型配置；需要模型但未配置时明确失败，不以编辑距离或首项自动兜底。

确认仍为 `PUT /api/v1/recommendations/confirm`，复用原子消费、权限/目录/版本/epoch/期限重验、持久 operation_id、保存失败重试与丢响应后查询/原载荷重放。不得降级到普通切群。未确认结果仅保存在有界内存；取消通过本地代次失效并丢弃结果，服务端记录自然到期，本轮不新增服务端 token 撤销接口。

## 两端生命周期

浏览器转写清理后刷新权威状态，再请求目标核对。等待和查看期间门控 PTT 与其他变更；沿用职责推荐查看期间的原群收听规则。隐藏页面、失去使用权、关闭语音、切换身份、目录/版本变化和取消均丢弃迟到结果。确认先保存固定载荷，取得操作终态和最新 state、清除本地日志后再恢复群音频，始终未按麦。

板端复用推荐卡片和确认入口，明确显示“语音目标核对”。保持独立 VOICE 意图、原准备页及取消入口；确认卡片不能启动另一轮采集。整个核对期间暂停群媒体；取消/失效恢复权威原群，已提交确认等待原操作终态后恢复当前群。大结果使用现有 PSRAM 存储；不增加内部任务栈、不改变 TLS、NVS 配置或音频增益。

## 验证

Go 与端侧回归分别覆盖精确快路径无模型调用、模型辅助候选只读、同音/错字、否定、改口、歧义、未授权目标、非法输出、提示注入、请求意图冲突、候选/版本变化、过期、取消迟到、确认丢响应和未按麦恢复。Fake 模型只证明软件边界，不证明语义准确。

固定合成文本集通过生产 HTTP/控制/文本模型链路评估，不接麦、不播放、不确认切群。标签在首次真实调用前冻结，结果与源版本分别记录；ASR、实体屏幕、触摸、口述目标和确认后音频恢复仍需实际验收，不能用文本评估或旧镜像通过结论替代。
