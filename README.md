# 声路同行 · Miku Intercom

面向小组即时协作的智能语音对讲工具。让分散的小组随时沟通，需要协助时，一句话找到对的组。活动执行、户外结伴、车队出行都可使用同一套核心能力。

首版目标：快速建群与口令入群、按住说话、按群名语音切换、断线后可信恢复。根据需求推荐协作群为增强项。普通群音频由独立对讲服务转发，RTA 只用于主动触发的语音指令。
