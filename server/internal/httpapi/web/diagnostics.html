声路同行 · 本机音频诊断

合成音源，真实 WebRTC 编解码；不代表系统麦克风 / 扬声器听测。只有点击下方按钮才创建声音。测试身份独立，不读取产品身份；不使用板子、RTA 或真实音频。自动矩阵是同页三个逻辑终端，不能称作三个独立浏览器。

三终端自动矩阵

尚未创建音源或测试身份。

包含双向、一对多、跨群、释放、同时抢麦、故意持续上行后的租约到期、十次切群。并发和失联属于开发驱动器，不改变普通页面的松手 / 失焦规则。
