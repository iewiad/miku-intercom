# 声路同行：本机控制面

第一切片提供建群、口令入群、当前群切换和麦权控制状态。页面明确显示“尚无音频”，不会请求麦克风、调用 RTA 或连接板子。

需要 Go 1.24+；浏览器状态测试使用 Node.js 22+。Go 仅依赖标准库。

```sh
cd server
go run ./cmd/intercom
```

打开[本机页面](http://127.0.0.1:8080)。默认快照为仓库 `work/intercom/state.json`，数据不进 Git。可通过 `-addr`、`-data` 显式设置；`-data` 的现有父目录必须是私有目录（0700），程序不会修改上级目录权限。默认只在本机运行，公开部署前另补 HTTPS、访问控制与配额。

使用两个独立浏览器配置或普通/隐私窗口创建不同身份。A 建立全员群，B 使用口令加入；再建立后勤组，第二次加入不改变当前群。两端按住控制按钮检查唯一授权、松手释放与手动切群。显示的是已加入成员数，不是在线人数。Token 只保存在浏览器本机存储，服务端保存摘要；群口令仅在创建后显示一次。

```sh
go test -race ./...
node --test internal/httpapi/web/*.test.js
```

快照保存群、成员、当前群版本与切群操作结果；麦权在重启后清空。使用 Ctrl-C 正常停止；一个快照只允许一个服务进程。异常退出会保留 `<快照路径>.lock` 目录，必须人工确认原进程已结束后才能移除此锁，不要删除或重置仍在使用的数据。

接口与后续开发顺序由 [文档 PR #1](https://github.com/iewiad/miku-intercom/pull/1) 中的 `docs/specs/002-control-api.md`、`docs/architecture.md`、`docs/development.md` 维护。控制状态通过不代表群实音频、板端或语音切群已通过。
